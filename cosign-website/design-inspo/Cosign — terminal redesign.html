Issue comments and merged PRs are easy to edit after the fact. Cosign runs each approval through six checks before it will call a record "signed" — the same six checks, every time.

review & approval · 3 passed

✓ passsnapshot.lock

Exact snapshot capture

The issue or PR content is hashed at routing time, so the version a signer reviewed can never quietly drift from the version they approved.

✓ passintent.review

Declared intent review

Each signer sees the exact approval meaning and checklist before deciding to approve, reject, or send it back for changes.

✓ passreauth.check

Fresh re-authentication

Approvers are challenged again at sign time, so a decision is tied to a live identity check, not a session left open in a browser tab.

operational controls · 3 passed

✓ passmanifest.pdf

Audit-ready PDF manifests

A finished approval generates a tamper-evident PDF with signers, timestamps, declared intent, and the frozen record — ready to hand to an auditor.

✓ passfile.github

GitHub filing by design

The signed evidence is filed into a repository your org already owns, so the compliance artifact stays in the same place as the work.

✓ passdrift.alert

Change detection alerts

If the routed issue or PR changes before every signer has acted, the request is flagged stale and pushed back for re-freeze.

Built for the frameworks your auditor already knows.

From design review to release sign-off, Cosign gives your team one approval path, anchored to the exact GitHub content being reviewed — no shadow spreadsheet, no second system of record.
